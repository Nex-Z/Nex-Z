# Icon sources

The SVG artwork is fitted inside a 48px tile with light and dark backgrounds.

- Go Gopher: https://go.dev/images/gophers/blue.svg — Renee French, CC BY 4.0 (https://go.dev/blog/gopher).
- Ferris: https://rustacean.net/ — Karen Rustad Tölva, CC0.
- Gin: https://github.com/gin-gonic/logo — Javier Provecho, CC BY 4.0; Gopher eyes by Renee French, CC BY 3.0. License: https://github.com/gin-gonic/logo/blob/master/LICENSE
- Spring Boot: https://spring.io/img/projects/spring-boot.svg — Spring project branding; used to identify the technology.

Other icons are served by Skill Icons (https://github.com/tandpfun/skill-icons).
